RUANG WAWASAN - STARTER WEBSITE

Teknologi:
- HTML
- CSS
- JavaScript
- Live Server (VS Code)

CARA MENJALANKAN:
1. Ekstrak folder ruang-wawasan.
2. Buka VS Code.
3. Pilih File > Open Folder, lalu pilih folder ruang-wawasan.
4. Pasang ekstensi "Live Server" jika belum ada.
5. Klik kanan index.html > Open with Live Server.

HALAMAN:
- index.html      : Beranda
- artikel.html    : Materi pembelajaran
- kuis.html       : Kuis interaktif
- diskusi.html    : Refleksi dan pedoman diskusi
- referensi.html  : Daftar rujukan dan kredit

CATATAN PENTING:
1. Bagian kronologi polemik masih berupa kerangka verifikasi. Lengkapi dengan sumber primer dan pemberitaan tepercaya sebelum dipublikasikan.
2. Halaman referensi berisi daftar yang perlu dilengkapi. Cantumkan hanya sumber yang benar-benar dibaca dan digunakan.
